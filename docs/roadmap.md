# Roadmap

No scheduled tasks. The previous roadmap is fully implemented and cleared; `software-design.md`, `software-requirements.md`, and `README.md` describe the system as it is today.

## How to use this file

Add tasks here when new work is planned. For each task, describe:

- **Problem**: what is wrong or missing today.
- **Work**: what needs to be done.
- **Acceptance criteria**: what defines "done".

Tick a task off (`- [x]`) when complete and fold the resulting behavior into the design and requirements documents so they keep describing the system as it actually is.
